how I work · 01–03

I start from the friction in a workflow, test AI options against it, build something simple, put it online and write down why I made each choice.

  1. 01

    Build tools and scripts

    Small, single-purpose code: a Python pipeline from PDF to cited answer, ESP32 firmware in C/C++, and a NEWS2-based alert engine in JavaScript covered by 40 Jest tests.

  2. 02

    Test AI options rigorously

    3 chunking strategies against 5 retrievers on a 48-question set I wrote, scored with Hit@k, MRR and bootstrap confidence intervals. Hybrid search showed no significant gain, so I shipped the simpler pipeline.

  3. 03

    Deploy so people can use it

    Vercel serverless functions that keep API keys off the browser, Docker images, GitHub Actions and a Jenkins pipeline on AWS EC2. Most projects have a live link.

how I work · 04–06

  2. 05

  3. 06

    Document the decisions
