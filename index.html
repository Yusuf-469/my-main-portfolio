MedDoc RAG

Citation-grounded question answering over 8 WHO, CDC and NIH guidelines, 1,077 pages in total.

Problem
An answer pulled from a long guideline is only useful if each claim can be traced to its source, and if the system refuses questions the documents do not cover.
Flow
  1. 8 PDFs
  2. Section-aware chunks
  3. bge-small + FAISS
  4. Cross-encoder rerank
  5. Grounded LLM
  6. Citation check
  7. FastAPI
Built
PyMuPDF parsing, section-aware chunking, bge-small embeddings with FAISS and cross-encoder reranking, feeding a grounded LLM answer that is checked against its citations. Served with FastAPI and Streamlit, packaged with Docker, with pytest and GitHub Actions CI. Built on pretrained models.
Safety
A relevance gate that refuses out-of-scope questions, citation validation, a prompt-injection classifier, output validation, and red-teaming.
Tested
3 chunking strategies against 5 retrievers, including BM25 with Reciprocal Rank Fusion, on a 48-question golden set I wrote and checked. Scored with Hit@k, MRR and paired bootstrap confidence intervals. Section-aware chunking won. Adding BM25 to dense search showed no significant gain, so I shipped the simpler pipeline.
Result
95.8% Hit@5 and 0.741 MRR on that 48-question set. 44 of 48 answers correct in my manual audit. 11 of 11 out-of-scope questions refused. 0 citations to sources the model was not given.

One question is 2.1 points on a 48-question set. The models are pretrained. Educational project, not medical advice.

HealthMonitor

Vital-sign readings from an ESP32 to a web dashboard, with an alert engine based on NEWS2.

Problem
Turn raw pulse, oxygen and temperature readings into alerts a person can read, instead of a stream of numbers.
Flow
  1. MAX30102 + DS18B20
  2. ESP32
  3. Wi-Fi
  4. Firebase RTDB
  5. Alert worker
  6. Express API
  7. Dashboard
Built
ESP32 firmware in Embedded C/C++ reading a MAX30102 (heart rate, SpO2) and a DS18B20 (temperature) into Firebase Realtime Database. An alert engine with NEWS2 scoring, adaptive per-patient baselines (z-score), escalation and a clinician-feedback step. A Node.js/Express REST API on Vercel secured with JWT, Helmet, rate-limited login, Firebase Auth and device API keys. A live Chart.js dashboard.
Tested
40 Jest tests.
Result
Dashboard deployed on Vercel.

Academic project. Not a medical device.

Academic

Neuro

An end-to-end ML pipeline that classifies healthy and mood-disorder subjects from EEG band-power features, with SHAP explanations and a FastAPI service.

Problem
Classify mood disorders from EEG data on a small dataset (n = 361), and check the model beats the simplest possible guess.
Flow
  1. EEG features
  2. Feature engineering
  3. StandardScaler
  4. PCA
  5. SMOTE
  6. 9 ML/DL models
  7. 5-fold CV + test
  8. SHAP
  9. FastAPI
Built
Imputation, StandardScaler, PCA and SMOTE (applied to training data only), plus engineered FAA and theta/alpha biomarkers. Python, Pandas, NumPy, scikit-learn, XGBoost and LightGBM, with SHAP for explanations and FastAPI for serving.
Tested
7 ML and 2 deep learning models (ANN, CNN-LSTM) compared with stratified 5-fold cross-validation, then on 73 held-out samples against a majority-class baseline of 73.7%.
Result
XGBoost and the voting ensemble reached 80.82% test accuracy against the 73.7% baseline, on 73 held-out samples. At that size there is about 9 points of uncertainty.

Academic project. Not a diagnostic tool.
